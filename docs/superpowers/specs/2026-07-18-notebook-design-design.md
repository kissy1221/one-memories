# one memory デザイン刷新 設計書（大学ノート案）

日付: 2026-07-18
対象: フロントエンド全画面（LP / ログイン / メイン / アカウント設定）
ステータス: ユーザー承認済みモックアップ（`.superpowers/brainstorm/` 参照）に基づく

## 背景と目的

現行デザインは stone 系グレー + amber のカードUIで、汎用的なミニマルデザインの域を出ない。
「1日1回ひとことだけ書き、1年後に蘇る」というプロダクトの本質に合わせ、
**「机の上に開いた1冊の大学ノート」** をコンセプトに全画面を刷新する。

ブラウザモックアップで3案を比較し、ユーザーが「B. 大学ノートの再現」を選択。
実画面適用イメージ（表紙ヒーロー + 見開きページ + 貼り紙の1年前）も承認済み。

## デザインコンセプト

画面はカードの寄せ集めではなく、**1枚の連続したノートページ**として構成する。
一貫ルール: **「ユーザーの言葉は手書き（Klee One）、UIは活字（ゴシック/明朝）」**。
ユーザーが書いたものだけがインクの手書き文字になり、アプリ側の文字は印刷物として区別される。

シグネチャー要素（この順に優先）:

1. **貼り紙の「1年前」** — 去年のページを切り取って貼ったような、少し傾いた生成りの紙片 + 赤みのテープ
2. **欄外の日付** — 赤いマージン線の左（欄外）に日付を置き、本文と分離する
3. **表紙ヒーロー** — LPは黒い表紙のノートに貼られたラベルが看板になり、CTAは「ノートをひらく →」

## デザイントークン

### 色（Tailwind `theme.extend.colors` に登録）

| トークン名 | 値 | 用途 |
|---|---|---|
| `desk` | `#4A4E45` | ページ外側の背景（深緑の机） |
| `paper` | `#F7F3E8` | ノートの紙面 |
| `rule` | `#BFCBD4` | 罫線（青灰） |
| `margin-red` | `#D66A5E` | 左マージンの赤線・テープ・アクセント |
| `ink` | `#3B3A36` | 本文・見出しの墨色 |
| `pencil` | `#8A857C` | 補助テキスト（鉛筆書きのグレー） |
| `scrap` | `#FFFDF6` | 貼り紙の紙色（枠は `#E0D9C4`） |
| `cover-dark` | `#22252B` | LP表紙の黒（Tailwind 既存の `bg-cover` と衝突するため `-dark` 付き） |
| `ink-red` | `#A6453B` | エラー文言・残り文字数警告（`margin-red` はコントラスト不足のため読ませる赤はこちら） |

コントラスト注意: `pencil` は小さい文字では `#736E64` まで暗くして 4.5:1 を確保する。
罫線・装飾は情報を持たないため低コントラストで良い。

### タイポグラフィ（Google Fonts、`index.html` で読み込み）

| 役割 | フォント | 使用箇所 |
|---|---|---|
| Display | Zen Old Mincho (700/900) | ロゴ「one memory」・LP見出し・ページタイトル |
| 手書き | Klee One (400/600) | ユーザーの投稿本文・入力中のtextarea・貼り紙の中身のみ |
| UI | Zen Kaku Gothic New (300/400/500) | ボタン・ラベル・説明文・日付 |

Noto Sans JP は廃止し、`tailwind.config.js` の fontFamily を
`sans`(Zen Kaku Gothic New) / `display`(Zen Old Mincho) / `hand`(Klee One) の3系統に置き換える。

### レイアウト定数

- 罫線ピッチ: `28px`（本文の line-height と一致させ、文字が罫線の上に載る）
- 罫線の描画: `repeating-linear-gradient(to bottom, transparent 0 27px, rule 27px 28px)` のユーティリティクラス `bg-ruled` を index.css に定義
- マージン線: 紙面左から `78px`（モバイルは `56px`）に赤い縦線。日付・曜日はその左の欄外に右寄せ
- 紙面: 最大幅 `~560px` 中央寄せ、左辺は綴じ影（グラデーション）、角丸は右側のみ大きく `2px 8px 8px 2px`
- 影・傾き: 貼り紙のみ `rotate(-0.7deg)` + 小さな影。それ以外の要素に傾き・強い影は使わない（装飾過多の回避）

## 画面別設計

### 1. LP（HeroPage）

- ファーストビュー: 深緑の机の上に黒い表紙のノート。表紙のクリーム色ラベルに
  「毎日ひとことの日記帳」「one memory」「今日のひとことが、1年後の宝物になる。」（手書き）。
  ラベル下に「氏名：あなた　1冊目」。CTAボタン「ノートをひらく」
- スクロール後: 開いたページ（paper + 罫線）の上で機能紹介。既存 FEATURES の4項目を
  罫線上の手書きメモとして並べる。「1年前の記憶」セクションは貼り紙演出の実物サンプルで見せる
- 最下部CTA: 奥付風の中央寄せセクション + 「ノートをひらく」
- ナビ: 表紙上部に小さく「ログイン」テキストリンクのみ

### 2. ログイン / 新規登録（AuthForm）

- 机の上にノートのラベル風カード（paper 色・角丸小さめ・細い枠線）
- 見出し「one memory」は Zen Old Mincho。入力欄は下線のみ（罫線に書き込むイメージ）で
  rounded-full をやめる
- ボタンは ink 色の矩形（角丸 3px 程度）

### 3. メイン画面（ログイン後）

画面全体が1枚の開いたノートページ。上から:

1. **ページヘッダー**: 左にロゴ（明朝）、右に「🔥 n日目」「設定」「ログアウト」（小さくpencil色）
2. **今日の欄**: 罫線エリア。1行目に「M月D日（曜）　きぶん {絵文字}」
   - 未投稿時（PostForm）: textarea が罫線の上に直接手書きフォントで乗る。
     気分ピッカーは日付行に横並び。文字数カウンターと「書きとめる」ボタンは欄の右下
   - 投稿済み（TodayCard）: 同じ見た目の読み取り専用表示
3. **1年前（OneYearAgoCard）**: 貼り紙。「1年前のきょう ─ YYYY年M月D日」+ 手書き本文 + 赤みテープ
4. **過去の投稿**: 罫線が続き、月の区切りは「─ 2026年7月 ─」の中央小見出し。
   各行: 欄外に「D 曜」、本文行に「{絵文字} 本文」（手書きフォント）。
   カード枠は使わず、ページに直接書かれている見た目
5. **奥付セクション（ページ最下部）**: 細い区切り線の下に Reminder / Export をまとめる。
   トグル・セレクト等の既存ロジックは維持し、見た目のみ notebook トーンに
6. **空状態**: 白紙の罫線ページに「まだ何も書かれていません。最初のひとことをどうぞ。」
7. **ローディング**: 罫線ページ + 薄いスケルトン行

### 4. アカウント設定（UserSettings）

メイン画面と同じノートページの上に、見出し「アカウント設定」（明朝）と
メール/パスワード変更フォーム。入力欄は下線スタイル、ボタンは ink 矩形。「← 戻る」はページ上部に。

## 実装方針

- **ロジック・状態管理・API・コンポーネント分割は変更しない**。JSX の構造と className、
  一部コピー（文言）の変更に限定する
- 変更ファイル: `frontend/index.html`（フォント読込・title）、`frontend/tailwind.config.js`（トークン）、
  `frontend/src/index.css`（`bg-ruled` 等のユーティリティ）、`frontend/src/App.jsx`（全コンポーネントの見た目）、
  `frontend/src/test/App.test.jsx`（文言変更への追随）
- コピー変更: 投稿ボタン「つぶやく」→「書きとめる」、LPのCTA「無料ではじめる」→「ノートをひらく」。
  その他のラベルは既存を維持してテスト変更を最小にする
- アクセシビリティ: 気分ピッカー・トグルの aria-label 維持、`focus-visible` リングを ink 色で明示
  （暗背景〔机・表紙〕上のボタンは paper 色に上書きして視認性を確保）、
  装飾要素（罫線・テープ・表紙）は `aria-hidden`。アニメーションは transition のみで
  `prefers-reduced-motion` の影響を受ける演出は追加しない
- レスポンシブ: 欄外幅 78px→56px、表紙ヒーローは縦積み、紙面の左右パディング縮小

## テスト

- 既存の `App.test.jsx`（vitest + testing-library）を全て通す。
  文言変更（つぶやく→書きとめる 等）に該当するアサーションのみ更新
- 追加テスト: LP表紙のCTA「ノートをひらく」の表示とクリックで認証画面へ遷移すること、
  投稿ボタン「書きとめる」で投稿できること（既存テストの文言更新で担保）
- バックエンド（rspec）はデザイン変更の影響を受けないが、ブランチ作業の区切りで一応実行する
- 手動確認: `docker compose up` でスクリーンショットを取り、モックアップと突き合わせる
